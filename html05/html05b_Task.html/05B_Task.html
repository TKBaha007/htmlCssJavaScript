Colors, Fonts, and Text

Colors Fonts Text

Colors

This paragraph should stand out with a light yellow background.

Fonts

You set the font once on body, and every heading, paragraph, and link on the page uses it.

Google Fonts gives you hundreds of free fonts. This page uses Roboto.

Text

Text properties control alignment, spacing between lines, and underlines. For example, text-decoration: none; removes the underline from links like this one.

CSS helps separate presentation from content, making styling easier to manage.

When you're done: the whole page uses Roboto on a light gray background, no links are underlined, the nav links are bold, two items are highlighted yellow, and the featured paragraph is light text on a dark background.
